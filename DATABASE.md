# Инструкция по локальному запуску PostgreSQL (Без Docker)

В соответствии с вашим планом, мы запускаем PostgreSQL локально на Windows. Все исходные данные из дампов MySQL сконвертированы в PostgreSQL-совместимый файл **`ce76279_sutki_postgres.sql`**.

Вот подробная пошаговая инструкция, как установить СУБД, создать базу данных и импортировать таблицы с данными.

---

## Шаг 1. Установка PostgreSQL на Windows

Если PostgreSQL ещё не установлен на вашем компьютере, установите его одним из двух способов:

### Способ А (Быстрый, через консоль Windows)
Откройте PowerShell от имени Администратора и запустите команду:
```powershell
winget install PostgreSQL.PostgreSQL
```
После установки перезагрузите терминал.

### Способ Б (Через установщик)
1. Скачайте официальный установщик для Windows: [ссылка на загрузку PostgreSQL](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads) (рекомендуется версия 15 или 16).
2. Запустите установщик. Во время установки:
   - Оставьте портом по умолчанию **`5432`**.
   - Задайте пароль для суперпользователя `postgres` (например, `postgres` или ваш собственный). **Запомните этот пароль!**
   - Убедитесь, что отмечена галочка установки **pgAdmin 4** (это графический интерфейс управления БД).

---

## Шаг 2. Создание базы данных и импорт данных

Выберите наиболее удобный для вас способ импорта: графический интерфейс pgAdmin или командную строку psql.

### Способ 1. Импорт через pgAdmin 4 (Рекомендуемый визуальный способ)
1. Откройте приложение **pgAdmin 4** (устанавливается вместе с PostgreSQL).
2. В левой панели разверните **Servers** $\rightarrow$ **PostgreSQL ...** и введите пароль суперпользователя, который вы указали при установке.
3. Нажмите правой кнопкой мыши на ветку **Databases** и выберите **Create** $\rightarrow$ **Database...**
4. В поле **Database** введите имя базы данных: `ce76279_sutki`. Нажмите **Save**.
5. Нажмите правой кнопкой мыши по созданной базе данных `ce76279_sutki` и выберите пункт **Query Tool** (Инструмент запросов).
6. Откройте файл `ce76279_sutki_postgres.sql` в текстовом редакторе, скопируйте весь текст запросов и вставьте в окно Query Tool в pgAdmin.
7. Нажмите кнопку **Execute/Refresh** (иконка «Play» или горячая клавиша `F5`).
8. После успешного завершения запроса обновите список таблиц в схеме (`Schemas` $\rightarrow$ `public` $\rightarrow$ `Tables`). Вы увидите импортированные таблицы.

### Способ 2. Импорт через командную строку (psql)
Если утилиты PostgreSQL добавлены в системный путь (PATH):
1. Откройте PowerShell в папке проекта (`c:\Users\USER\Desktop\sutkiru`).
2. Создайте базу данных:
   ```bash
   createdb -U postgres ce76279_sutki
   ```
   *(Система попросит ввести пароль пользователя postgres)*
3. Импортируйте сконвертированный файл дампа:
   ```bash
   psql -U postgres -d ce76279_sutki -f ce76279_sutki_postgres.sql
   ```

### Шаг 3. Применение мобильных миграций
Для работы мобильного приложения и нового бэкенда нужно применить дополнительные таблицы (избранное, чаты, пуш-токены и т.д.).
- **Через pgAdmin**: Откройте файл `backend/db/migrations/000001_mobile_additions.up.sql`, скопируйте его содержимое в Query Tool базы `ce76279_sutki` и выполните его (F5).
- **Через консоль (psql)**:
  ```bash
  psql -U postgres -d ce76279_sutki -f backend/db/migrations/000001_mobile_additions.up.sql
  ```

## Подключение из Go бэкенда

В вашем Go-приложении строка подключения (DSN) к базе данных будет выглядеть следующим образом:

```env
DATABASE_URL=postgres://postgres:<ваш_пароль>@localhost:5432/ce76279_sutki?sslmode=disable
```

### Важные нюансы схемы:
- Таблица **`"user"`** создана с двойными кавычками, так как слово `user` является ключевым (зарезервированным) словом в PostgreSQL. В SQL-запросах на бэкенде обязательно экранируйте её двойными кавычками: `SELECT * FROM "user";`.
- Все булевые поля из MySQL (например, `deleted`, `pay`, `enable`, `is_verified`), имевшие тип `tinyint(1)`, сконвертированы в тип `boolean` со значениями `true`/`false`.
