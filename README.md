# VIGAZH component kit

Пакет общих компонентов и примеров их применения. Структура `src` сохранена: файлы можно сравнивать и переносить в проект без восстановления путей вручную.

## Основа UI-kit

- `src/shared/ui` — кнопки, поля, текстовые роли, хедеры, табы, сортировка, модалки, подтверждения, алерты и остальные примитивы.
- `src/shared/styles` — общие стили и правила экранов, на которых компоненты уже внедрены.
- `src/shared/lib` — небольшие зависимости UI-kit (`cx`, адаптивность, тема, прокрутка и валидация).
- `src/shared/types` — типы фильтров, нужные примерам списков.

## Готовые составные компоненты

- `src/pages/profile/ui/ProfileHeader.tsx` — единый хедер личного кабинета; `onSettings` необязателен, поэтому гостю показывается тот же хедер без настроек.
- `src/features/profile` — профильные поля, выбор даты рождения и редактор фотографии.
- `src/features/requests` — карточка, деталка и окна действий заявки.
- `src/features/reviews` — карточки, рейтинг и предупреждения отзывов.
- `src/features/my-listings` — подтверждение публикации объявления.
- `src/features/search-filters` — фильтры и переиспользуемые панели выбора.

## Страницы-примеры

В `src/pages` лежат экраны, уже переведённые на компоненты: профиль гостя и пользователя, уведомления, заявки, отзывы, сообщения и «Мои объявления».

## Важные правила проекта

- Размеры текста: 22, 18, 16, 14, 12 и 9 px через текстовые компоненты.
- Жирность задаётся снаружи: 400 или 500.
- Цвет и обрезание текста задаются снаружи.
- Кнопки: `sm`, `md`, `lg`; цвет задаётся через `tone`, формат — через `mode`.
- Кнопки подтверждений — `sm`, кнопки футеров — `md`.
- Удаление в подтверждениях — красная прозрачная кнопка с окантовкой.
- Мобильные и планшетные размеры нельзя менять без отдельной проверки.
- Зелёные основные кнопки не используются; основные действия оранжевые.

Сначала перенесите `src/shared/ui`, затем стили и только после этого составные компоненты/страницы.
