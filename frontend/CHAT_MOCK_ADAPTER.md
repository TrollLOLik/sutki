# Временный слой данных чата

Чат работает через репозиторий с единым интерфейсом:

- `src/features/chat/data/chatRepository.ts` — контракт данных;
- `src/features/chat/data/mockChatRepository.ts` — временная реализация в памяти вкладки;
- `src/features/chat/data/index.ts` — единственная точка подключения адаптера;
- `src/features/chat/data/seed.ts` — демонстрационные переписки, сообщения и бронирования.

## Текущее поведение

Данные существуют только в памяти JavaScript. Можно отправлять, изменять и удалять сообщения, добавлять локальные вложения, подтверждать и отклонять бронирования, архивировать и закреплять диалоги. После перезагрузки страницы всё возвращается к исходным примерам. `localStorage` для чата не используется.

## Как подключить реальный сервер

1. Создать `ApiChatRepository`, реализующий интерфейс `ChatRepository`.
2. В `src/features/chat/data/index.ts` заменить одну строку:

```ts
export const chatRepository = new ApiChatRepository();
```

Компоненты чата, фильтры и маршруты менять не потребуется. Для WebSocket-событий реализация репозитория должна обновлять свой snapshot и вызывать подписчиков.
