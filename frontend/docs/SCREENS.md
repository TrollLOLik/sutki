# Готовые экраны

| Маршрут | Экран | Данные |
|---|---|---|
| `/` | Главная, поиск, быстрые и полные фильтры | локальные данные |
| `/map` | Интерактивная заглушка карты | локальные данные |
| `/listing/:id` | Детальная страница объявления | локальные данные |
| `/booking/:id` | Форма заявки на бронирование | session/local demo |
| `/create` | Многошаговое размещение объявления | черновик в localStorage |
| `/profile` | Профиль и полноценные настройки | localStorage |
| `/messages` | Список чатов | session mock |
| `/chat/:id` | Диалог, вложения и карточки брони | session mock |
| `/incoming` | Входящие заявки | session mock / HTTP adapter |
| `/incoming/:id` | Детали входящей заявки | session mock / HTTP adapter |
| `/bookings` | Исходящие заявки и брони | session mock / HTTP adapter |
| `/bookings/:id` | Детали исходящей заявки | session mock / HTTP adapter |
| `/ui-kit` | Каталог UI Kit внутри приложения | локально |

Все существующие экраны сохранены при рефакторинге. Заявки не удалялись.
