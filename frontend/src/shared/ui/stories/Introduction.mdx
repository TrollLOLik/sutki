# Sutki UI Kit

UI Kit проекта «Сутки» — это семантические токены, адаптивные React-компоненты и продуктовые паттерны для поиска жилья, чатов, заявок, бронирований и профиля.

## Правила

1. Страницы собираются из `shared/ui`, `entities`, `features` и `widgets`.
2. Цвета и размеры не хардкодятся в продуктовых компонентах — используются CSS-переменные и токены.
3. Любой новый компонент получает story с базовыми, интерактивными, disabled, loading и dark-состояниями.
4. Любое обращение к данным идёт через repository-интерфейс. Session mock и HTTP-адаптер имеют одинаковый контракт.
5. Мобильная и desktop-компоновки используют одни данные и действия, но могут иметь разные widgets.

## Быстрый старт

```bash
npm run storybook
npm run generate:page -- favorites "Избранное"
npm run generate:ui -- PriceBreakdown
```

Открытый каталог UI Kit внутри приложения: `/ui-kit`.
